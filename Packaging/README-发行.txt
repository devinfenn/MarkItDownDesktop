MarkItDownDesktop 0.1.4（Windows x64）

安装与使用
运行安装包，按向导选择安装位置。可选桌面快捷方式和文件右键菜单。
正常启动会打开桌面界面；右键文件转换时，Markdown 会直接保存在原文件目录。
打开应用后，选择或拖入 PDF、DOCX、PPTX、XLSX、XLS、CSV、HTML 或 TXT 文件，然后点击“开始转换”。

安装包已包含 MarkItDown 0.1.8、Python 运行环境、.NET 8 和 Windows App SDK 运行组件。
不需要另外安装 Python 或 MarkItDown。
转换在本机完成；默认把 Markdown 保存到原文件旁边。设置中可改输出位置。
遇到同名 Markdown 文件时，程序会生成带数字后缀的新文件，避免覆盖。

源码和构建脚本位于 MarkItDownDesktop 项目。
